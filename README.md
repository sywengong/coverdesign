# 封面设计师 - 短视频封面生成工具

一款功能强大的纯前端短视频封面设计工具，基于 HTML5 Canvas 技术构建，无需服务器即可运行。支持多平台尺寸预设、丰富的元素类型、图层管理、历史记录等完整的设计功能。

## ✨ 功能特性

### 🎨 多平台封面尺寸
- **通用**：1080×1920（9:16 竖屏）
- **抖音**：1080×1920（标准竖屏）
- **小红书**：1242×1660（3:4 比例）
- **微信**：1080×1260（接近方形）
- **Instagram**：1080×1080（1:1 方形）
- **横幅**：1920×1080（16:9 横屏）

### 📝 丰富的元素类型
1. **文字元素**
   - 支持中文字体（微软雅黑、黑体、宋体、楷体等）
   - 支持英文字体（Arial、Georgia、Times New Roman 等）
   - 自动检测系统可用字体
   - 字号、粗细、对齐方式可调

2. **图片元素**
   - 支持本地图片上传
   - 自动适应画布尺寸
   - 支持 CORS 跨域图片加载
   - 加载失败自动使用占位图

3. **形状元素**
   - 矩形（支持圆角）
   - 圆形/椭圆
   - 三角形
   - 星形
   - 可设置填充色、边框、圆角半径

4. **贴纸元素**
   - 爱心 ❤️
   - 星星 ⭐
   - 火焰 🔥
   - 闪光 ✨
   - 花朵 🌸

### 🖼️ 背景设置
- 纯色背景（颜色选择器）
- 渐变背景（线性渐变，支持多方向）
- 背景图片上传

### 核心类说明

#### 1. CanvasEditor（画布编辑器）
负责画布渲染、元素管理、背景绘制、选择框绘制等核心功能。

**主要方法：**
- `setSize(width, height)` - 设置画布尺寸
- `setBackgroundColor(color)` - 设置背景颜色
- `setGradient(...)` - 设置渐变背景
- `addText(text)` - 添加文字元素
- `addImage(src)` - 添加图片元素
- `addShape(type)` - 添加形状元素
- `render()` - 渲染画布
- `exportAsImage()` - 导出为图片
- `exportProject()` - 导出项目数据
- `importProject(data)` - 导入项目数据

#### 2. CanvasElement（基础元素类）
所有元素的基类，定义元素的通用属性和方法。

**属性：**
- `id` - 唯一标识
- `type` - 元素类型
- `x, y` - 位置坐标
- `width, height` - 尺寸
- `rotation` - 旋转角度
- `opacity` - 不透明度
- `visible` - 是否可见
- `locked` - 是否锁定

**方法：**
- `getBounds()` - 获取边界框
- `containsPoint(x, y)` - 检测点是否在元素内
- `render(ctx)` - 渲染元素
- `toJSON()` - 序列化为 JSON

#### 3. TextElement（文字元素）
继承自 CanvasElement，用于显示文字内容。

**特有属性：**
- `text` - 文字内容
- `fontSize` - 字体大小
- `fontFamily` - 字体族
- `fontWeight` - 字体粗细
- `color` - 文字颜色
- `textAlign` - 对齐方式

#### 4. ImageElement（图片元素）
继承自 CanvasElement，用于显示图片。

**特有属性：**
- `src` - 图片源地址
- `imageData` - 图片数据（Image 对象）

**方法：**
- `loadImage(src)` - 异步加载图片

#### 5. ShapeElement（形状元素）
继承自 CanvasElement，用于绘制各种形状。

**特有属性：**
- `shapeType` - 形状类型（rectangle, circle, triangle, star）
- `fill` - 填充颜色
- `stroke` - 边框颜色
- `strokeWidth` - 边框宽度
- `borderRadius` - 圆角半径

#### 6. ElementManager（元素管理器）
负责管理所有画布元素，提供增删改查、层级管理等功能。

**主要方法：**
- `addElement(element)` - 添加元素
- `removeElement(id)` - 删除元素
- `selectElement(id, isMultiSelect)` - 选中元素
- `bringToFront(id)` - 置顶
- `sendToBack(id)` - 置底
- `moveUp(id)` - 上移一层
- `moveDown(id)` - 下移一层

#### 7. LayerManager（图层管理器）
管理图层列表，提供图层排序、选择、显示/隐藏等功能。

#### 8. App（应用主类）
整个应用的入口类，负责初始化、事件绑定、UI 更新等。

**主要功能：**
- 初始化画布编辑器
- 绑定工具栏事件
- 绑定图层事件
- 绑定属性面板事件
- 绑定背景设置事件
- 处理画布交互（拖拽、缩放、旋转）
- 更新图层列表
- 更新属性面板
- 项目保存/加载/导出

## 🚀 使用方法

### 1. 直接打开
由于项目是纯前端实现，无需服务器环境，直接用浏览器打开 `index.html` 即可使用。

### 2. 本地服务器（推荐）
如需使用图片上传功能，建议启动本地服务器：

```bash
# Python 3
python -m http.server 8000

# Node.js
npx serve

# VS Code Live Server 插件
```

然后访问 `http://localhost:8000`

### 3. 基本操作流程

1. **选择画布尺寸**：在左侧面板选择目标平台尺寸
2. **设置背景**：选择纯色、渐变或上传背景图片
3. **添加元素**：
   - 点击"文字"添加文本
   - 点击"图片"上传本地图片
   - 点击形状按钮添加几何图形
   - 点击贴纸添加装饰元素
4. **编辑元素**：
   - 点击选中元素
   - 拖拽移动位置
   - 拖拽控制点调整大小
   - 拖拽旋转手柄旋转元素
5. **图层管理**：在右侧面板调整图层顺序
6. **对齐元素**：使用对齐按钮快速排列元素
7. **导出作品**：点击"导出图片"保存为 PNG
